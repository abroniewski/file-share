# file-share

A repository used to share files publicly via GitHub — currently containing a pitch deck PDF.

## The Problem

- Sharing large files or documents without requiring recipients to have access to a specific cloud storage service.
- GitHub provides a stable, publicly accessible URL for any file in a public repository.

## Scope & Status

- **Project type:** File hosting convenience repo
- **Current state:** Active (add files as needed)
- **Known limitations:**
  - Not suitable for versioning binary files at scale (Git LFS not configured).
  - No access controls; all files are public.

## Contents

- `Smart-Mobility-AI-Powered-Solutions-for-Carbon-Efficient-Aviation Pitch Deck.pdf` — a pitch deck on AI-powered smart mobility solutions for carbon-efficient aviation.

## Who This Is For

Anyone who has been sent a direct link to a file in this repository.
